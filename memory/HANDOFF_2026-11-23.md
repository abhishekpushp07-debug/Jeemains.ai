`book_publish.py` (shrink_new), `smart_imports.py`, `imports.py`, `written.py`. Naap (`test_reports/png_measure*.json`,

(pixel same). Sirf nayi save hone wali picture chhoti hoti hai. Jo picture har request par source PDF se banti hai
(`derivatives.render_crop` -> `tejas_core._render_crop_png`), us raaste me yeh nahi bulaya jata. Preview DB me 164 file
hain: 134 ka kind `combined`, 30 bina kind, save hui PNG (`rendered_png`) 0. JEE Main PYQ live par isi raaste par hai ya nahi, alag se pakka nahi kiya.
