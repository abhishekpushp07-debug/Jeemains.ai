### A1–A3. Student Choice doors (short shape)
- **A** `GET /api/choice/bank?exam=jee-main` → `{ "pick": true, "random": true, "max_questions": 75, "max_per_subject": null, "minutes_per_question": { "Physics": 2.4, "Chemistry": 1.6, "Mathematics": 3.2 } }`. 404 = both closed. Do NOT send "subjects" (chapters come from your chapter-wise catalogue). Read by the app's server only.
- **B** `GET /api/choice/chapters/<id>/questions?page=1` (id = the chapter-wise test's set id) → `{ "chapter": {id, title, subject}, "pages": 2, "items": [ { "id", "number", "type": "mcq"|"integer", "text", "stem": [ {url, w, h} ] } ] }`. NEVER options, answer or solution. Picture links: https, open without cookies, valid ≥ 24 h. ~50 a page.
- **C** `POST /api/choice/papers` `{ "exam": "jee-main", "mode": "pick", "question_ids": [...], "request_key": "<uuid>" }` or `{ ..., "mode": "random", "count": 30, ... }` → `{ "set_id": "..." }`. Same request_key = same paper. 1 to 75 questions (never 90). +4 / −1 / 0. Minutes = Maths 3.2 + Physics 2.4 + Chemistry 1.6 a question, sum rounded UP (a made paper is NOT cut at 180). Random split equal over the 3 subjects, leftovers to Physics then Chemistry (10 → 4+3+3). Order: Physics, Chemistry, Mathematics; single-correct first. `test_kind: "choice"` on the set AND on its result. Refusal: 422 with a plain sentence (shown as it is). Owned by the student, listed nowhere else.
