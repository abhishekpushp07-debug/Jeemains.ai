# Authentication testing contract
Use /app/memory/test_credentials.md for owner credentials, never log secrets. Verify bcrypt hashes, unique normalized email, student-only registration, role checks, HttpOnly Secure cookies, revocation after logout, expiry and login throttling. Verify /api/auth/login, /me, /logout and /register using HTTPS preview with cookie session. No password recovery/email verification integration is included. Access and refresh JWTs use server-side session records to allow revocation. Cross-origin writes must be denied. Student A cannot read student B attempts, source files, crops or reports. No OAuth bypass exists.
