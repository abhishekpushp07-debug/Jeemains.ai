## Root cause (proven)
The Physics Ch14 mock stays `held` because its two blocking issues live on SOLUTION regions of page 309 that the mobile Quick-Fix flow cannot satisfy:
1. Q3 solution region has `continuation:true` (mis-segmented solution spanning Q3→Q5). The quick-fix sets answer/`checked=true` but leaves `continuation:true`, so the recheck keeps emitting "ambiguous worked-solution start/continuations". Proven by: region#3 on page 309 is checked:true/answer:"A"/continuation:true AND the owner submitted Q3=A 7× (audit) with the issue still present in mock.issues.
2. Q11 solution region is `checked:false`/`answer:""` ("source region needs review") and is never surfaced to the owner (no Q11 quick-fix exists in audit).

Secondary: page-level issues for page 309 are `[]` while mock-level issues still list both — the page-clear path and the mock recheck path are inconsistent, so the owner sees the page "fixed" yet the mock won't release.

## Suggested fixes
- CODE (E1): In the quick-fix / recheck handler for book mocks, (a) when an owner confirms a solution region via the card, clear/resolve the `continuation` ambiguity flag (or re-run solution segmentation) so the "ambiguous worked-solution start/continuations" issue can actually clear; (b) ensure every blocking region — including unchecked solution regions like page 309 Q11 — is surfaced in the Fix card / /problems payload so the owner can act on it; (c) reconcile page-level `issues` clearing with the mock-level recheck so they cannot disagree. Target files: the admin books "fix" POST handler and the mock recheck/issue-recompute function (search backend for the /mocks/{id}/fix route and the issues/continuation logic).
- USER (owner): The second blocking item (page 309 "Q11 — source region needs review") has never been fixed from the card — only Q3 was retried. Until the code fix lands, the mock cannot be released from the UI because the Q3 `continuation` flag is not clearable via answer-entry alone.
- Note: the 409 Conflict is a harmless double-submit/stale-revision rejection, not the cause.
