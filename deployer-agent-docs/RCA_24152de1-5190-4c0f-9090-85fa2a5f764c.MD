## IMPORTANT TOOL CONSTRAINTS (affects a few items)
The read-only query tool supports only `count | find | distinct | list_collections | list_indexes`. It has **no `aggregate`/`$group`/`collStats`/`maxTimeMS`/`allowDiskUse`**. Consequences:
- **`storageSize` and `totalIndexSize` are NOT obtainable** with available tooling (requires `collStats`). Reported as N/A below. Document counts and full index lists ARE available.
- **True `$group` duplicate detection is not possible.** Where a UNIQUE index enforces the grouping key, duplicates are reported as 0 (DB-enforced). Where no unique index exists (e.g. book_mocks book_id+order), duplicates were computed client-side from a projected `find`.
- Field-to-field comparisons use `$expr`; bsonType counts use `$type` buckets; cross-collection "joins" done via `$in`/`$nin` against id-sets pulled with `distinct`.
