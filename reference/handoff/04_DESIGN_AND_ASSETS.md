## Native controls
Use native screen layout/navigation; at least48dp touch targets even though web question buttons are44px. Status must use icon/label/shape as well as color. TalkBack labels include question number, subject, outcome and selected state. Semantic tab roles, focus restoration and a visible active score version are required.

Solution navigation is a horizontal scroll rail, not wrapping question numbers over many rows. Keep selected question visible on launch, rotation, subject changes and restored state. Exactly one question/solution card follows it. Correct/incorrect/skipped/marked distinction is accessible; no false confidence from color alone.

Light/dark shell is supported, but question/source PDF/typed mathematical reading surfaces stay white with dark readable text as in the current app. Honor system font scale, reduced motion, edge-to-edge insets, landscape and keyboard behavior. No heading should disappear behind a corner ribbon or sticky toolbar.
